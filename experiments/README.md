# Experiments

A scripted-interlocutor harness for running the adversarial-control study proposed in [`analysis/adversarial-control-design.md`](../analysis/adversarial-control-design.md) and pre-registered in [`analysis/pre-registration-adversarial-control.md`](../analysis/pre-registration-adversarial-control.md).

**Start here: [HANDOFF.md](HANDOFF.md).** It's written to be self-contained for a local Claude Code session (or a human) picking this up fresh, with API keys and real model access — something a cloud session building the harness can't safely do itself.

Two files are still DRAFT and need review before any real session runs: [`interlocutor-rules.md`](interlocutor-rules.md) and [`pre-registration-addendum-DRAFT.md`](pre-registration-addendum-DRAFT.md).
